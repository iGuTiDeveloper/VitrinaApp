# 👟 Vitrina App — Sistema Comercial & Control de Bodega de Calzado

**De tu stock al chat de tu cliente.**  
*Vitrina* es una Single Page Application (SPA) ligera, práctica y minimalista diseñada específicamente para comerciantes y vendedores de calzado y sneakers. Permite la gestión centralizada de inventario multitalla, control comercial, registro rápido de ventas y un módulo dedicado para el control de devoluciones y reintegro al stock.

## ✨ Características Principales

- **📦 Registro Multitalla por Curvas:** Carga masiva de pares por modelo mediante curvas estructuradas:
  - **Curva Dama:** Tallas 36 a 39.
  - **Curva Caballero:** Tallas 40 a 44.
  - **Curva Personalizada:** Para numeraciones o tallas especiales.
- **🏷️ Identificación por Código Único:** Búsqueda rápida e inteligente mediante códigos de 4 dígitos o modelo.
- **⚠️ Alertas Inteligentes de Inventario:** Diagnóstico automático del estado del stock (*"Inventario en Buen Estado"* vs *"⚠️ Alerta: Inventario Bajo / Agotado"*).
- **🛒 Módulo de Ventas en Vivo:** Descuento automático del inventario y registro contable en tiempo real.
- **↩️ Gestión Comercial de Devoluciones:** Módulo para pedidos no reclamados o cambios, con función de **Reintegro al Stock con 1 solo clic**.
- **💾 Persistencia de Datos:** Todos los registros se conservan de forma permanente en la memoria local (`localStorage`).
- **📱 Interfaz Adaptativa & Modo Oscuro Permanente:** Formato *Mobile-First* optimizado para celulares y computadores, con estética *Dark Mode* que evita la fatiga visual.
- **📊 Exportación de Datos:** Descarga directa del historial de ventas en formato CSV.

---

## 🛠️ Tecnologías Utilizadas

- **HTML5 & JavaScript (ES6+):** Lógica nativa autocontenida en un único archivo.
- **Tailwind CSS:** Framework de estilos para un diseño moderno y fluido.
- **FontAwesome 6:** Iconografía intuitiva.
- **LocalStorage API:** Persistencia de datos local sin necesidad de backend complejo.
